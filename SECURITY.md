Security
========

If you have found a security vulnerability in the Antimatter Desktop App, please report it privately rather than in a
public issue: use GitHub's [private vulnerability reporting](https://github.com/AntimatterChat/desktop-app/security/advisories/new)
for this repository, or follow [antimatter.chat/help.html#security](https://antimatter.chat/help.html#security).
We will keep you updated while we fix it and, if you wish, credit you in the release notes.

Security fixes are released as new versions of the app; the app tells you about them when update checks are on.
